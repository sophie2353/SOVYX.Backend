TÉRMINOS DE PRIVACIDAD Y MANEJO DE DATOS

SODIE v3.5 — Especificaciones de Seguridad, Acceso y Datos Requeridos.

1. NATURALEZA DEL SOFTWARE Y ACCESO DE EVALUADORES

SODIE funciona única y exclusivamente como software de segmentación de audiencia para Meta Ads donde accederán en primera fase después de la fase 0 (con 3 evaluadores) 50 personas.

No es una agencia de Facebook Ads donde tardan 3 semanas en pedir todos los datos y no tienes una supervisión real de las métricas ni notificaciones en tiempo real.

No se necesita otra cosa más que el acceso como evaluador en Meta y los datos de ventas anteriores.

2. SEGURIDAD Y CREDENCIALES

Jamás se pedirán número de cuenta, contraseña o visuales para las campañas. El inicio de sesión y aceptación de ser evaluador al igual que subir los visuales y monto requerido para cada campaña es mediante la plataforma de Meta, no mediante SODIE.

3. LOS ÚNICOS DATOS REQUERIDOS

  • Aceptar ser evaluador: Extrayendo el act_id y pixel_id de tu cuenta publicitaria para inyectar segmentación directamente desde el panel de Meta. No antes de llenar el formulario o pagar.
  • Excel con datos de clientes: (En v4 serán solo API de Shopify / Hotmart que actualizará las campañas automáticamente).

No se necesitan más datos. SODIE es creada para ahorrar tiempo y miles de dólares donde el usuario SIEMPRE ingresará su monto a invertir en la campaña y sus visuales.

4. REVOCACIÓN DE ACCESO Y ELIMINACIÓN DE DATOS

Al quitar el acceso de evaluador, automáticamente se eliminan los datos del act_id y el pixel_id donde ya no se podrá visualizar las métricas ni crear la segmentación adecuada para las campañas publicitarias de Facebook. SODIE no podrá hacer nada al respecto después de eliminar el acceso porque se necesita segmentación previa, visuales y tarjeta para invertir en alguna campaña del usuario; por ende, los datos se eliminan automáticamente del sistema.

5. ¿POR QUÉ PLATAFORMAS CRIPTO?

Al ser 3 evaluadores, el camino más rápido al no ser una suscripción mensual para verificar el funcionamiento del SOFTWARE es mediante plataformas cripto porque agiliza los trámites, donde en la V4 sí será mediante pasarela y suscripción mensual de $5.000 al mes (podría subir el precio a $10K-$15K/mes por ROAS generado a los 3 evaluadores) mediante resultados de los 3 evaluadores y el mío principalmente en 3 nichos diferentes donde la V4 será más ágil y precisa. Teniendo que pagar 50K$ de acceso (48K$ si se reservo el cupo de 2.000$)

Con plataformas normales de pasarela tardaría la V4 entre 30 y 60 días para activarse. Con Pago Cripto es solo mínimo 7 días desde el último pago (Semana 3) hasta tener lista la V4. Las cuotas correspondientes fueron para verificar el software a largo plazo con constantes segmentaciones nuevas cada 24 horas. El pago respectivo para equipo y actualizaciones necesarias es un total de 150K$. por ende, el pago de reserva y evaluador es puramente inversión en la V4 lo antes posible y no 4 meses después. Cada semana se iran subiendo actualizaciones con nuevas funciones / diseños de los clientes, incluyendo chat directo con la persona que creo este software.

6. FORMULARIO PRE PAGO Y COMUNICACIONES

Este formulario es única y exclusivamente para mejorar la segmentación de SODIE hacia siguientes campañas. No se enviarán emails al correo o se escribirá por WhatsApp ofreciendo el servicio.

La única forma de recibir algún Gmail de SODIE es que hayas accedido a la lista de espera, donde ni siquiera hace falta porque activas las notificaciones push en la web y sabes cuando se activa la versión 4.
